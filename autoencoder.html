Data

Windows of 128 samples (40 ms) of 50 Hz mains. The checked classes make up the test set; with Train on: clean mains only the network never sees a disturbance while it learns.

The test set has 48 windows of every checked class, generated separately.

The whole autoencoder

The encoder squeezes the 128 samples through a dense layer into the code — k numbers — and the decoder rebuilds the window from them alone. A dense layer is drawn as one box, a bar per unit; the code as one small box per number. The output box shows the reconstruction (blue) over the input (grey) and the squared error underneath. Click anything — a unit, a code number, a sample of the output — to see how it is computed.

The encoder halves the length three times — convolution, ReLU, max pool: 128 → 64 → 32 → 16 — and a dense layer turns the last maps into the code; the decoder goes back the same way, repeating every value (upsampling) before each convolution. Every box is one channel's map. The output box shows the reconstruction (blue) over the input (grey) and the squared error underneath. Click a box for its arithmetic.

Experiment · how many numbers does a window need?

Trains a fresh autoencoder of the current kind for every code size k = 1, 2, 3, 4, 8, 16 and measures how well it rebuilds clean mains and how well its error separates the disturbances. A clean 50 Hz window is a sine of fixed frequency: amplitude and phase — two numbers — describe it.

Things to try

  • Train on clean mains only and watch the AUC table: every disturbance the decoder cannot rebuild scores high. With all 8 classes, k = 2 and 40 epochs the MLP autoencoder reached a mean AUC of 0.98–0.99 over two runs, the convolutional one 0.95–0.99 — without a single label.
  • The hardest classes are the frequency drifts (over, under): a slightly faster or slower sine is still a sine, and the decoder rebuilds it almost as well (AUC 0.87–0.99 depending on the run). Spikes, sags, bursts, ripple and harmonics sit at 1.00.
  • Pick a disturbed example in the Inspector and look at the red error band under the output: it peaks where the disturbance is. For the MLP the largest error fell inside the disturbance in 97–100% of the test windows, for the convolutional autoencoder in about 90%.
  • Set k = 2 and watch the latent space: clean windows lie on a ring — the two numbers have learned amplitude and phase, the angle around the ring being the phase. With k = 1 there is no room for both: the error on clean mains stays about 40 times larger and the mean AUC drops to about 0.6. Run the sweep below to see the knee.
  • Switch Train on to every checked class. The code now has to describe the disturbances as well — but at k = 2 there is little room, so the mean AUC only fell to about 0.97; the drifts lose most.
  • Tick denoising with k = 8: the network gets a noisier copy and must return the clean signal. At an added noise of 0.1 the MLP raised the SNR from 16.5 to 26.6 dB — better than a 5-point moving average (23.0 dB). The convolutional autoencoder reached 22.2 dB, no better than the simple filter.
