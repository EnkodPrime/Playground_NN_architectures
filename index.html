The "unknown" state

Softmax is normalised — it measures which of the known classes fits best, not whether anything fits at all. So "unknown" needs a separate score over the logits or the features, plus a threshold. Calibration runs the score over the test set (trained classes) and over the classes you left out (never seen by the network) — the overlap of the two histograms is exactly the price you pay: false alarms against missed novelties.

Quantisation

Training always runs in float32; the panel quantises a copy and evaluates it alongside, so the cost of every bit width is visible while the network learns. Weights only — activations stay in float, which is what weight-only quantisation means on a microcontroller. The histogram shows one weight tensor with the quantisation levels drawn over it: when the red grid gets coarser than the spread of the weights, accuracy starts to go. Turning on keep weights quantised leaves them rounded in place, so the kernels in the diagram and every number in the arithmetic panel become the values a fixed-point device would actually use.

Watermark (black-box)

Triggers are derived from the key: a clean sine plus 2–3 interharmonics locked exactly +18.5 Hz above a harmonic with a fixed phase — a combination no real grid produces, so the deliberate misclassification never fires in the field. Each trigger gets a key-derived pseudo-random label, which makes the signature the pattern of answers rather than one single class: guessing that a trigger set exists does not reveal the mapping.

Things to try — GNN

  • The graph is not given, it is built. A single voltage window has no natural graph, so the signal makes one: sample i sees sample j when everything between them is lower. Nothing here is learned — the topology is a function of the waveform.
  • Look at the arc diagram in the inspector while switching the example class. A clean sine gives an almost regular graph with max degree around 8; a single impulse becomes a hub that sees roughly twice as far. That difference is what the network reads.
  • Aggregation matters. Mean smooths the neighbourhood, max picks the loudest neighbour — which suits impulses, since a hub node then inherits the peak directly.
  • Two layers reach two hops. With one layer a node only knows its neighbours; add a layer and information travels one hop further. Click a channel in layer 2 and compare its inputs with layer 1.
  • Node features are only value, step difference and magnitude — no frequency information at all. Whatever the network learns about ripple or harmonics has to come through the topology.

Things to try — S4 / Mamba

  • S4D is a convolution in disguise. Nothing in it depends on the input, so the whole layer collapses to one FIR kernel of the full window length. Hover a channel: the inspector shows that exact kernel and its frequency response, computed from the state modes.
  • Read the mode table. Click a channel: each mode has |Ā| — how much of the state survives one sample, so memory ≈ 1/(1−|Ā|) — and a resonant frequency taken from the angle of Ā. That is how a handful of state variables cover the whole band.
  • Δ is the timescale. One number per channel decides both memory length and where the modes sit in frequency. Channels are initialised across decades so they cover different bands.
  • Switch to Mamba and the kernel disappears from the inspector — replaced by Δ(t). Making Δ, B and C depend on the input breaks time invariance, which is exactly what lets the model ignore some samples and write others into the state.
  • Both blocks end in a nonlinearity — SiLU for S4, the gate branch for Mamba. Without it the recurrence is linear and the entire stack collapses into a single linear map, which cannot separate these classes at all.

Things to try — RNN

  • Start with GRU, mean readout, 8 units. It is the fastest of the three to converge here: roughly 97% on four classes within a hundred epochs.
  • Simple RNN vs gated cells — the plain tanh cell stalls around 50%. Backpropagating through 128 steps without gates is the vanishing-gradient problem, live.
  • LSTM needs noticeably more epochs than GRU on this task, and its cell state can saturate: click a unit and watch |c| in the state update — once tanh(c) sits at ±1, the gradient through it is gone.
  • Readout matters — last state forces the network to carry information all the way to the end of the window, while mean over time lets every step contribute. Impulses favour max.
  • Bidirectional doubles the units: → ones read the window forwards, ← ones backwards. Click a ← unit and see how the highlighted history flips to the other side of the window.
  • Compare with the CNN on the same data: a convolution sees a fixed receptive field, while a recurrent unit sees everything up to t — the selection overlay shows the difference.

Things to try

  • Ripple vs clean — two filters with K=5 in a single layer are enough. Switch the maps to “Spectrum” to watch the filter turn into a band detector around 400–900 Hz.
  • Impulses — pick the Global Max Pool head: it reacts to a single position in the window instead of the average, which is exactly the right logic for a transient.
  • Voltage sag — ReLU with average pooling reaches roughly 90%, while the Abs activation goes past 97%: it turns the filter into an envelope detector. Global Max Pool fails here, since a maximum cannot see a dip.
  • Harmonics — longer kernels (K=9 over K=5) help, because the receptive field has to cover a decent part of the cycle. The inspector shows its value.
  • All six classes — with 2×4 filters the network stalls near 60%; give it 2×8 filters and a learning rate of 0.01 and it clears 90%.
  • Raise the background noise to 0.15 and watch the gap between training and test loss open up — that is overfitting; push back with L2.
