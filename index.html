Cell structure

Each box is one filter — inside it is that filter's output map for the current example, and in the top-left corner the learned kernel itself. Link thickness is weight magnitude ( positive, negative). Hover for a quick look, click a node for the full arithmetic below.

The window is cut into 16 patches of 8 samples (2.5 ms); each becomes a token of d numbers — by default the largest response of d short filters in that patch (a convolutional tokenizer). Every box is one of those d dimensions across the 16 tokens. Above each encoder column is its attention map — row: the token that looks, column: the token it looks at, averaged over the heads; hover a box for each head on its own. Click a box to follow one token through attention and the feed-forward net; the slider picks the token.

Each column is one residual block — three convolutions (K = 8, 5, 3 by default), layer norm after each, and a skip from the block input added before the last ReLU; each box is one output channel's map. The dashed window is everything the block can see around t. Click a channel for the block's cell — conv, norm, ReLU, skip — and the arithmetic below.

Each column is one Inception module: a 1×1 bottleneck, three convolutions of length 5, 11 and 23 side by side and a max-pool branch, stacked into one map, normalised and passed through ReLU. The coloured tag on every box says which branch the channel comes from. Click a channel to see all four branches at t; hover one for how strongly each branch responds to this example.

Each box is one hidden unit. In the first layer it shows the unit's 128 weights — one per sample, a fixed template laid over the window ( positive, negative); deeper boxes show the weights from the units before. The bar at the bottom is the unit's output for this example. Click a unit for its cell and arithmetic; in the first layer, where you click picks the input sample t.

Each box is one KAN node. In the first layer it shows φ(xi) — what each of its 128 edges delivers for this example; deeper boxes draw one learned edge function per input, with a red dot where this example lands. The node only adds its edges up; the bar is its value. Click a node for its edge functions and spline coefficients.

Each box is one hidden unit — inside it is its state ht across the whole window, which is what a recurrent net actually computes. Link thickness is the size of the input weights ( positive, negative). With a bidirectional layer, → units read the window forwards and ← units backwards. Click a unit for the step-by-step recurrence below.

The "unknown" state

Softmax is normalised — it measures which of the known classes fits best, not whether anything fits at all. So "unknown" needs a separate score over the logits or the features, plus a threshold. Calibration runs the score over the test set (trained classes) and over the classes you left out (never seen by the network) — the overlap of the two histograms is exactly the price you pay: false alarms against missed novelties.

Quantisation

Training always runs in float32; the panel quantises a copy and evaluates it alongside, so the cost of every bit width is visible while the network learns. Weights only — activations stay in float, which is what weight-only quantisation means on a microcontroller. The histogram shows one weight tensor with the quantisation levels drawn over it: when the red grid gets coarser than the spread of the weights, accuracy starts to go. Turning on keep weights quantised leaves them rounded in place, so the kernels in the diagram and every number in the arithmetic panel become the values a fixed-point device would actually use.

Watermark (black-box)

Triggers are derived from the key: a clean sine plus 2–3 interharmonics locked exactly +18.5 Hz above a harmonic with a fixed phase — a combination no real grid produces, so the deliberate misclassification never fires in the field. Each trigger gets a key-derived pseudo-random label, which makes the signature the pattern of answers rather than one single class: guessing that a trigger set exists does not reveal the mapping.

Things to try — Transformer

  • The tokens make the difference. Switch Tokens between the two. With linear patches each token is eight raw voltages, and attention has to discover from 480 windows what a ripple or an impulse looks like. With the convolutional tokenizer each token already says how strongly d short filters fired in its 2.5 ms. On four classes after 30 epochs at the default learning rate: conv tokens 68–79%, linear patches 55–63%, the 2×4 CNN 58–70%; on all eight classes after 40 epochs conv tokens 59% against 38% for the CNN. This is the fix the Compact Convolutional Transformer brought to small datasets.
  • Where attention looks depends on the tokens. With linear patches an impulse lights up a column: layer 1 put 0.18–0.23 of every token's attention on the patch with the impulse, three to four times an even share (1/16 = 0.06). With conv tokens the impulse is already in its token, and attention stayed at about an even share (0.05) — it mostly averages. Hover the encoder boxes to see each head.
  • Heads need room. Every head gets d / heads numbers for its queries and keys. With one, q·k is a single product and attention can hardly tell the tokens apart — d = 4 with 4 heads gave 37–47% — so a head always gets at least two, and the options that would break that are switched off.
  • Encoder vs decoder. Tick causal: the maps turn triangular, because a token may only look at itself and the past — the form a Transformer uses on a stream. Here it did as well (78–94%): the classifier averages all tokens at the end anyway.
  • Follow one token. Click a box: in the token column the cell shows the filter at the 8 samples of the patch, the max and the position; in an encoder column it follows the token through LN, its attention over all 16 tokens as bars, the weighted sum, Wo, the residual and the feed-forward net.

Things to try — ResNet-1D

  • Normalisation is the big lever. Build 3 blocks (9 convolutions), pick 4 classes, run 20 epochs, and switch layer norm and skip connections on and off. In our runs (two each): layer norm with skips 99–100%, layer norm without skips 96–97%, no normalisation 69–91%. Without a norm, every ReLU block only adds, and the values grow from block to block.
  • Skips on top. With layer norm on, the skips are worth a few more points at the end (99–100% against 96–97%) — the difference the 1D CNN's residual toggle could not show without normalisation.
  • Against the plain CNN. After 20 epochs, two blocks of 6 channels reach 94–99% on four classes where the 2×4 CNN is at 44–58%, and 55% on all eight classes where it is at 17%.
  • Why layer norm and not batch norm. Batch norm needs a whole mini-batch at once; this engine trains one example at a time. A batch norm that used running averages instead made training worse (38–66%), so each map is normalised over its own channels and positions. Click a channel: the cell diagram shows conv → LN → ReLU three times, and the skip joining before the last ReLU; the table lists μ, σ, γ and β.

Things to try — InceptionTime

  • Which branch answers? Train on All 8, then hover a channel of module 1: the bars show how strongly each branch responds to the current example. In our runs the long K=23 branch was clearly the most active for Harmonics (0.48 against 0.31–0.36 for every other class) — a kernel that long covers enough of the cycle to see the 3rd and 5th harmonic.
  • Four views at once. Click a channel: the cell diagram shows the bottleneck, all four branches with their value at t, and how the stacked map is normalised. Move t along the window and watch the four values change.
  • A slow starter. The loss can sit at ln 4 ≈ 1.39 — equal odds for every class — for several epochs before it moves. On four classes, two modules reached 44–88% after 10 epochs and up to 99% after 20, but about one run in five was still at 25%. If it has not moved after 10 epochs, press ⟳ for a fresh start; a faster learning rate does not help.
  • The shortcut. With three modules the original adds one shortcut around all of them, through a 1×1 convolution — the arc from the input to module 3. Skip connections turns it off.

Things to try — MLP

  • Same task, no convolution. Pick Clean / Ripple and run 60 epochs here and in the 1D CNN playground. The 2×4 CNN (118 parameters) reaches about 99% test accuracy; this MLP with 8 units (1,050 parameters) stays near 50% — a coin toss.
  • Why. Hover a first-layer unit: its 128 weights are a template fixed to positions in the window. The ripple is a small 420–900 Hz tone at a random frequency and phase, so a fixed template cannot catch it wherever it sits. A CNN uses the same few weights at every position and then averages — where the ripple is no longer matters.
  • Memorising instead of learning. Set Run for to 300. Training accuracy climbs past 90% while test accuracy stays around 60–70%: the MLP learns the training windows, not the disturbance. Watch the two loss curves drift apart.
  • Spectrum view. Switch Feature maps to Spectrum: each first-layer box then shows which frequencies its template matches.

Things to try — KAN

  • Every edge is a function. Hover a node in layer 2: its box draws one learned curve per input, and the red dot is where the current example lands. Click it for the coefficients: φ(x) = wb·silu(x) + Σ cm·Bm(x), with cubic B-splines on a grid of 5 intervals — 9 numbers per edge.
  • The node does nothing but add. An MLP puts the nonlinearity on the node and a single weight on the edge; a KAN turns that around. Compare the cell diagram of a KAN node with an MLP unit.
  • Same weakness as the MLP, only stronger. The first layer has a curve for every input sample — 128 × 4 edges × 9 = 4,608 parameters and nothing shared across positions. On Clean / Ripple training accuracy reaches about 98% after 300 epochs while test accuracy stays near 60%.
  • The grid follows the data. A first-layer node adds 128 edges, so its value can be ±40 — far outside a spline grid of −2 … 2. Layer 2 therefore reads its inputs standardised, u = (h − μ)/σ, with μ and σ tracked during training; the shaded band in its curves is that grid in the units that actually arrive.

Things to try — GNN

  • The graph is not given, it is built. A single voltage window has no natural graph, so the signal makes one: sample i sees sample j when everything between them is lower. Nothing here is learned — the topology is a function of the waveform.
  • Look at the arc diagram in the inspector while switching the example class. A clean sine gives an almost regular graph with max degree around 8; a single impulse becomes a hub that sees roughly twice as far. That difference is what the network reads.
  • Aggregation matters. Mean smooths the neighbourhood, max picks the loudest neighbour — which suits impulses, since a hub node then inherits the peak directly.
  • Two layers reach two hops. With one layer a node only knows its neighbours; add a layer and information travels one hop further. Click a channel in layer 2 and compare its inputs with layer 1.
  • Node features are only value, step difference and magnitude — no frequency information at all. Whatever the network learns about ripple or harmonics has to come through the topology.

Things to try — S4 / Mamba

  • S4D is a convolution in disguise. Nothing in it depends on the input, so the whole layer collapses to one FIR kernel of the full window length. Hover a channel: the inspector shows that exact kernel and its frequency response, computed from the state modes.
  • Read the mode table. Click a channel: each mode has |Ā| — how much of the state survives one sample, so memory ≈ 1/(1−|Ā|) — and a resonant frequency taken from the angle of Ā. That is how a handful of state variables cover the whole band.
  • Δ is the timescale. One number per channel decides both memory length and where the modes sit in frequency. Channels are initialised across decades so they cover different bands.
  • Switch to Mamba and the kernel disappears from the inspector — replaced by Δ(t). Making Δ, B and C depend on the input breaks time invariance, which is exactly what lets the model ignore some samples and write others into the state.
  • Both blocks end in a nonlinearity — SiLU for S4, the gate branch for Mamba. Without it the recurrence is linear and the entire stack collapses into a single linear map, which cannot separate these classes at all.

Things to try — RNN

  • Start with GRU, mean readout, 8 units. It is the fastest of the three to converge here: roughly 97% on four classes within a hundred epochs.
  • Simple RNN vs gated cells — the plain tanh cell stalls around 50%. Backpropagating through 128 steps without gates is the vanishing-gradient problem, live.
  • LSTM needs noticeably more epochs than GRU on this task, and its cell state can saturate: click a unit and watch |c| in the state update — once tanh(c) sits at ±1, the gradient through it is gone.
  • Readout matters — last state forces the network to carry information all the way to the end of the window, while mean over time lets every step contribute. Impulses favour max.
  • Bidirectional doubles the units: → ones read the window forwards, ← ones backwards. Click a ← unit and see how the highlighted history flips to the other side of the window.
  • Compare with the CNN on the same data: a convolution sees a fixed receptive field, while a recurrent unit sees everything up to t — the selection overlay shows the difference.

Things to try

  • Ripple vs clean — two filters with K=5 in a single layer are enough. Switch the maps to “Spectrum” to watch the filter turn into a band detector around 400–900 Hz.
  • Impulses — pick the Global Max Pool head: it reacts to a single position in the window instead of the average, which is exactly the right logic for a transient.
  • Voltage sag — ReLU with average pooling reaches roughly 90%, while the Abs activation goes past 97%: it turns the filter into an envelope detector. Global Max Pool fails here, since a maximum cannot see a dip.
  • Harmonics — longer kernels (K=9 over K=5) help, because the receptive field has to cover a decent part of the cycle. The inspector shows its value.
  • All six classes — with 2×4 filters the network stalls near 60%; give it 2×8 filters and a learning rate of 0.01 and it clears 90%.
  • Raise the background noise to 0.15 and watch the gap between training and test loss open up — that is overfitting; push back with L2.
  • Residual (ResNet) — every layer after the first adds its input back, y = f(x) + x; the dashed arcs under the columns are those skips, and a filter's cell diagram shows where the skip joins. Build 8 layers and compare. Do not expect a jump: at this depth a plain stack still learns with Adam — the gradient reaching layer 1 is about as large with skips as without — and in our runs on four classes both reached 98–100% after 40 epochs with Tanh. With ReLU the skip adds a non-negative branch at every layer, so values grow with depth; residual ReLU stacks did no better and at 12 layers worse, which is why real ResNets put a normalisation in every block. The ResNet-1D tab has it, and there the skips do help.
